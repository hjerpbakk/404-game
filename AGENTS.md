# 404-game

A small browser game meant as a 404 page: a truck catches falling money emojis. A single static page, no build step.

## Run

Open `src/index.html` in a browser, or serve `src/` with any static server. There is no package.json and no test suite.

- Game code is inline in `src/index.html`. The rest of `src/` is icons and the web manifest.
- It is deployed as part of hjerpbakk.com (`/games/404-game`), not from this repo.
